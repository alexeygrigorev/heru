# Migrating to Heru 2.0.0

Heru `2.0.0` removes the legacy prompt-first `--engine` CLI form.

Use the positional engine syntax instead:

```bash
heru claude "find the bug in src/foo.py"
```

## What changed

- The removed prompt-first `--engine` form is no longer accepted.
- `heru <engine> <prompt>` is the only supported direct CLI shape.
- Shared engine options such as `--resume`, `--continue`, `--cwd`,
  `--model`, `--max-turns`, and `--raw` still live on the engine
  subcommands.

## Litehive impact

- Litehive-owned direct `heru` command snippets, tests, and helpers must
  use positional engine syntax only.
- Litehive's own `litehive ... --engine ...` flags are unchanged; this
  migration only affects direct `heru` invocations.
- Refresh Litehive's vendored Heru wheel so `uv run` and `uv sync`
  resolve the new CLI contract.
